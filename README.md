# Sam Goldberg

Sam Goldberg's blog about biotech, food tech, and the business of new ideas.
Live at **https://samgberg.github.io/testing/** (once GitHub Pages is turned on).

## Write a new post

1. Add a file to the `_posts` folder named like `2026-10-06-my-post-title.md`.
2. Start it with this, then write your post below in plain text:

```
---
title: My Post Title
category: Biotechnology
summary: One sentence that shows up in the post list.
---

Your writing goes here.
```

Use an existing category (Biotechnology, Cellular Agriculture, Marketing, Reading List) or make up a new one; the Writing page groups posts by it.

## Other things to edit

- **About page:** `about.md`
- **Site name, email, LinkedIn:** `_config.yml`
- **Look and colors:** `assets/style.css`
