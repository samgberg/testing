# Sam Goldberg

Sam Goldberg's blog about biotech, food tech, and the business of new ideas.
Live at **https://samgberg.github.io/testing/** (once GitHub Pages is turned on).

## Write or edit a post (the easy way)

1. Go to **https://app.pagescms.org** (or `/edit/` on your site) and sign in with GitHub.
2. Click **Blog posts**, then **Add an entry** for a new post, or click any post to edit it.
3. Type in the writing box (spell check underlines mistakes in red), then click **Save**.

## Write a post by hand

Add a file to `_posts` named like `2026-10-06-my-post-title.md` that starts with:

```
---
title: My Post Title
category: Biotechnology
summary: One sentence that shows up in the post list.
---

Your writing goes here.
```

## Other things to edit

- **About page:** `about.md` (also editable in the editor)
- **Site name, email, LinkedIn:** `_config.yml`
- **Look and colors:** `assets/style.css`
